# TRYIT — Клуб Нового Досвіду

Статичний бізнес-сайт клубу нового досвіду **TRYIT** (м. Київ).

## Сторінки

- **Головна** (`index.html`) — концепція, переваги, пакети
- **Про нас** (`about.html`) — місія, візія, цінності, аудиторія
- **Активності** (`activities.html`) — каталог вражень
- **Події** (`events.html`) — календар майбутніх заходів
- **Як це працює** (`how-it-works.html`) — інструкція для нових учасників
- **Відгуки** (`reviews.html`) — досвід учасників + форма відгуку
- **Контакти** (`contacts.html`) — реєстрація, корпоративні заявки, контакти

## Технології

- Чистий HTML5 + CSS3 + vanilla JS
- Адаптивний дизайн (desktop + mobile)
- Premium lifestyle естетика
- Форми з фронтенд-симуляцією успішної відправки (готово до підключення Formspree / Telegram / backend)

## Розміщення на GitHub Pages

1. Створіть новий репозиторій на GitHub.
2. Завантажте всі файли з цієї папки в корінь репозиторію.
3. Settings → Pages → Source: Deploy from a branch → Branch: `main` → `/ (root)`.
4. Сайт буде доступний за адресою `https://<username>.github.io/<repo>/`.
